## How to read a sheet

Every `brag.md` follows the same structure: **Snapshot → Headline numbers → Accomplishments → Resume-ready bullets → Keywords → Soundbites → Artifacts & screenshots**. Not every sheet has every section.

| Tag | Meaning |
|---|---|
| ✅ Verified | Backed by an inspected artifact: git history, the GitHub API, a live site, or a repo file |
| 🟢 Documented | Consistent across my résumés and notes; no independent artifact was checked |
| 🟡 Estimate | A projection, grade estimate, or recollection. Read it as approximate |
| ❓ | Unknown or not yet recorded |

## About this repo

This is a **generated, sanitized export** of a larger private knowledge base. It covers selected projects only. Employer and client work, grades, and other people's names are left out on purpose. Teammates and sponsors are described by role, not by name.

The export is regenerated from the private source, so pull requests to the sheets will be overwritten. If you spot something wrong, open an issue or email me.
