# Oregon State University — AI Advisor (DRI-GENESIS)

## 1. Snapshot
James advised Oregon State's GENESIS AI development team, which builds internal agentic AI tools for a **35,000-student public research university**. The role had three parts:
- **Platform advice:** helped university teams adopt **Amazon Bedrock, Google Gemini and Microsoft Copilot**, working directly with the Google, Amazon and Microsoft vendor teams.
- **Teaching:** wrote training material and reference code for agentic AI.
- **Engineering:** built the **GENESIS AI Hub** agent registry on Google's **A2A** protocol. It became **OpenBeavs**, his senior capstone, now live at genesis.dev.oregonstate.edu.

## 3. Accomplishments
1. **Enterprise AI adoption.** Advised university teams on rolling out Amazon Bedrock, Google Gemini and Microsoft Copilot, and worked with each vendor's team on best-practice setup. Helped shape university AI governance.
2. **A2A interoperability.** Integrated Google's **Agent2Agent (A2A)** protocol so agents can register themselves and talk to each other securely. He also built the **Cyrano de Bergerac** reference system (an ADK orchestrator plus tone-classifier and writer agents, exposed as A2A servers) that the team used to teach agent-to-agent design.
3. **GENESIS AI Hub → OpenBeavs.** Engineered the full-stack agent registry (first React + FastAPI/Express on GCP, later SvelteKit + FastAPI on Cloud Run). It became **OpenBeavs**, the university's A2A agent hub; see the [OpenBeavs sheet](../../project/openbeavs/brag.md).
4. **Training material.** Wrote guides, documentation and example codebases on agentic coding (Claude Code, qwen-code), LLM integration, CI/CD with GitHub Actions, Typst and Microsoft SSO. The GENESIS org uses them for onboarding.
