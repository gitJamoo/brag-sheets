# BVR ST CO — Software Engineer

## 1. Snapshot
James worked as a software engineer at BVR ST CO, a sports-AI startup, alongside his last year at Oregon State. He built core pieces of **COORDINATOR**, the company's agentic AI framework for **real-time football game analysis**:
- **Local reasoning:** low-latency inference with **NVIDIA Nemotron** on local hardware, so coaching data stays in the building.
- **LoRA fine-tuning:** lets the system learn from verified real-time game outcomes.
- **Analysis pipelines:** ML pipelines for player-tracking data and computer-vision work on game film.

## 3. Accomplishments
1. **Agentic framework for live games.** Built core parts of COORDINATOR's agent framework. It ingests play-by-play, video and schematic data and gives tactical reads during a game, with a fast path for in-game calls and a slower path for deeper analysis between possessions.
2. **Local, private inference.** Used **NVIDIA Nemotron** for low-latency local reasoning on NVIDIA hardware (DGX Spark class), so team data never goes to a cloud API.
3. **Learning from outcomes.** Implemented **LoRA fine-tuning** so the model improves with reinforcement from verified real-time game outcomes.
4. **Film and tracking pipelines.** Built ML pipelines on player-tracking data and computer-vision models for automated game-film breakdown (recognizing formations and positioning).
